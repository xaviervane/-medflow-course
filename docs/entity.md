# Выделение сущностей MedFlow

На основе анализа предметной области выделен следующий список сущностей для проектирования базы данных.

## 1. Основные сущности

1. **Patient** (Пациент)
   - Физическое лицо, получающее медицинские услуги.
   - Хранит контактные данные, полис, адрес.

2. **Doctor** (Врач)
   - Сотрудник клиники, оказывающий медицинские услуги.
   - Имеет одну или несколько специализаций.

3. **Specialization** (Специализация)
   - Справочник медицинских направлений (например, "Терапевт", "Хирург").
   - Связана с врачами отношением многие-ко-многим.

4. **Service** (Услуга)
   - Справочник медицинских услуг с указанием стоимости и длительности.

5. **Appointment** (Запись на приём)
   - Факт бронирования времени. Связывает Пациента, Врача и Услугу в конкретное время.

## 2. Сущности медицинского процесса

6. **MedicalRecord** (Запись в медкарте)
   - Создаётся во время или после приёма. Содержит жалобы, анамнез, диагноз.
   - Привязана к конкретному Приёму (Appointment) и Пациенту.

7. **Prescription** (Назначение/Рецепт)
   - Список рекомендованных действий или лекарств.
   - Привязан к конкретной Записи в медкарте.

## 3. Сущности безопасности

8. **User** (Пользователь системы)
   - Учётная запись для входа в систему (управляется через ASP.NET Core Identity).
   - Имеет связь 1:1 (опционально) с Patient или Doctor для ролевого доступа.

---
*Примечание: Детализация атрибутов и типов данных для каждой сущности будет выполнена на Занятии 3.*
